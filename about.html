ABOUT THIS NOTEBOOK

지식을 찾는 길과
생각을 잇는 길.

DhammaReader 연구노트는 한국어 사용자가 불교의 경전과 개념을 더 쉽게 찾고 이해하도록 만드는 과정의 공개 기록입니다.

무엇을 기록하나요?

불교 용어와 문헌을 읽으며 생긴 질문, 서로 다른 전통의 설명, 자료를 연결하는 방법, 그리고 웹사이트를 만들며 내린 결정을 기록합니다. 확인된 사실과 아직 검토 중인 해석은 구분해 쓰겠습니다.

왜 기록하나요?

연구는 한 번의 결론보다 질문이 이어지는 과정에 가깝습니다. 어떤 자료를 보았고, 어떤 선택을 보류했으며, 다음에는 무엇을 확인해야 하는지 남기면 독자와 연구자 모두 같은 지점에서 다시 시작할 수 있습니다.

어떻게 참여할 수 있나요?

오류를 찾거나 더 좋은 원전·번역·연구 자료를 알고 있다면 GitHub Issues로 알려주세요. 글의 내용과 직접 연결되는 질문을 환영합니다. 서비스에서 경전을 읽으려면 DhammaReader를 방문해 주세요.

이 블로그는 연구 과정의 기록입니다. 개별 글의 주장과 근거는 글마다 확인해 주세요.
